## Description

Test the full `EvalRunnerAgent` flow end-to-end using a mock LLM and a small synthetic dataset. No real LLM or API calls.

## What to build

Suggested file: `tests/test_eval_runner_agent.py`

### Test cases

1. **Successful run** — mock LLM produces a `run_eval` tool call; assert the returned context dict contains a valid score report matching the schema defined in THP-116.
2. **Holdout access blocked** — verify the `run_eval` tool rejects any `data_split="holdout"` attempt (even if injected manually); assert the correct error is surfaced.
3. **All-errored run** — all examples in the synthetic dataset fail; assert the agent returns a graceful report (no crash, error counts correct, metrics default to `0.0`).
4. **Previous run diff** — a previous report exists at the configured output path; assert the score diff is included in the context when THP-116 specifies it should be.
5. **Tool call failure** — mock `run_eval` to raise an exception; assert the agent surfaces a structured error in the context dict rather than propagating the exception.

### Setup

- Use `tmp_path` for all file output.
- Mock the LLM client to return a deterministic tool-call response without making real API calls.
- Use a small synthetic dataset (3–5 examples, 2–3 route classes).
