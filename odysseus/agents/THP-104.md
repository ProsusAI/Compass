## Description

Write the system prompt for the LLM inside `EvalRunnerAgent`. The prompt governs how the agent invokes the eval harness, interprets the score report, and hands off results to the Review agent.

## What to build

The system prompt must instruct the agent to:

1. Extract `prompt_version` and `data_source` from the pipeline context.
2. Call `run_eval` with those parameters — never requesting `data_split="holdout"` (the tool enforces this, but the prompt must reinforce it).
3. Interpret the returned score report in the format defined by THP-116.
4. Put the structured score summary into the output context for the Review agent, using the schema agreed in THP-116.

Also cover error cases:
- High error rates in the run (e.g. >50% of examples failed).
- No previous run available for diffing.
- Tool call failures or timeouts.

Suggested file: `prompts/eval_runner_system.md` (or `.txt`)
