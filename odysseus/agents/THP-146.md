## Description

Integration tests for the User Input agent, implemented as Markdown scenario files that Claude Code reads and executes by orchestrating three sub-agents: a User Input Agent, a User Simulator, and a Verification Agent. Tests use real LLM API calls against the pre-configured Odysseus MCP server.
