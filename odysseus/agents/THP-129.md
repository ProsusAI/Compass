## Description

Implement the `run_eval` MCP tool in `odysseus/mcp.py` as designed in THP-114. This is the Python function the Eval Runner agent LLM calls to trigger an evaluation run. It wires up all concrete dependencies and delegates to `controller.run()`.

## What to build

```python
# odysseus/mcp.py
@mcp.tool()
async def run_eval(prompt_version: str, data_source: str) -> str:
    ...
```

Implementation steps:

1. **Wire RunDependencies** — construct a `RunDependencies` instance:
   - `LiteLLMBackend` (THP-113)
   - `FilePromptManager` (THP-87)
   - `JsonDatasetManager` (THP-90)
   - `DefaultMetricsEngine` (THP-88)
   - `JsonResultsCollector` (THP-91)
2. **Build RunConfig** — hardcode `data_split="dev"` (THP-115); never expose as a parameter.
3. **Call the controller** — `await controller.run(config, deps)` and handle exceptions at the tool boundary.
4. **Return the score report** — serialize `RunReport` into the format defined by THP-116.
5. **Surface errors** — return a structured error string if the prompt version is not found, the dataset is invalid, or the run fails entirely.
