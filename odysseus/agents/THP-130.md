## Description

Create `odysseus/agents/eval_runner.py` as a concrete `BaseAgent` subclass. This is the main implementation task for THP-76. The agent wraps an LLM call with the system prompt from THP-104 and the `run_eval` tool from THP-129 in its tool list.

## What to build

```python
# odysseus/agents/eval_runner.py

class EvalRunnerAgent(BaseAgent):
    @property
    def name(self) -> str:
        return "eval_runner"

    async def run(self, context: dict[str, Any]) -> dict[str, Any]:
        ...
```

The `run(context)` method must:

1. Extract `prompt_version` and `data_source` from the incoming pipeline `context` dict.
2. Execute the LLM agent loop with:
   - System prompt loaded from `prompts/eval_runner_system.md` (THP-104).
   - `run_eval` tool available (THP-129).
3. Continue the loop until the tool has been called and a score report is returned.
4. Put the structured score report into the returned context dict under the key(s) defined in THP-116.

Error handling: surface LLM failures, tool call failures, and malformed report responses as structured errors in the returned context dict rather than raising exceptions.
