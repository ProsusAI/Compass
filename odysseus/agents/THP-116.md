# THP-116 — Define the score report format the Eval Runner agent passes downstream

**Type:** Task  
**Status:** To Do  
**Epic:** [THP-76](https://prosus-thymo-thesis.atlassian.net/browse/THP-76) — Eval runner agent  
**Jira:** [THP-116](https://prosus-thymo-thesis.atlassian.net/browse/THP-116)

## Description

`RunReport` (in `odysseus/eval/models.py`) is already the raw output of `controller.run()`, containing `config`, `metrics`, `results`, and `summary`. `ResultsCollector` writes it to disk and logs a diff against the previous run. This task specifies what the Eval Runner agent LLM puts into the pipeline context for the Review agent to consume.

## What to design

1. **Included fields** — at minimum: aggregate metrics dict, `RunSummary` (total, succeeded, failed, cost, duration), and per-example error breakdown.
2. **Previous-run diff** — decide whether the diff (currently logged to stdout by `ResultsCollector.write_report()`) is surfaced inline in the context message or left to disk only.
3. **Context dict schema** — the exact key(s) and structure that `EvalRunnerAgent` outputs into the pipeline context dict. This schema is the contract with the Review agent.

## How it links with the rest of the codebase

| Touch point | Detail |
|---|---|
| `odysseus/eval/models.py` | `RunReport`, `RunSummary`, `EvalResult` are the source models. |
| `odysseus/eval/collector.py` | `ResultsCollector.write_report()` already computes and logs the diff. |
